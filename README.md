## ⚡ Funkce webu ShitBook
1. **Interaktivní E-Shop & Konfigurátor:**
   - Výběr modelů (ShitBook Pro 16″ Max, ShitBook Pro 14″ Redpill, ShitBook Air 13″ Incel Copium, Vintage Chernobyl i9).
   - Dynamický konfigurátor parametrů (čip, RAM, SSD, barva šasi) s živým přepočtem ceny a vlivem na SMV skóre.
   - Příslušenství: *ShitCloth™ iHadřík Ultra Max* (890 Kč), *Dongle Octopus™ 18v1 Chobotnice*, nálepky *8GB IS ENOUGH*.
2. **Plně funkční nákupní košík (Drawer):**
   - Správa položek, počítadlo kusů, kalkulace celku a uložení do `localStorage`.
   - Vtipné promo kódy (`COPIUM` pro 15% slevu za újmu, `KARLIN` pro 20% hipster přirážku, `8GB` pro pokutu 5 000 Kč).
   - Checkout modal s falešnou platbou (zástava rodného domu) a oslavou konfet.
3. **Kalkulačka MacBook Hypergamie (SMV Test):**
   - 5-krokový interaktivní test tvého laptopu a kavárenských návyků.
   - Vyhodnocení skóre 0–100 bodů, určení titulu (Karlínský Gigachad vs Sub-5 Incel), dosahu aury a šance na kontakt s baristou.
   - Možnost zkopírovat certifikát SMV do schránky.
4. **4 Zákony Hypergamie (Blackpill Manifest):**
   - Past 8 GB RAM, chromatická dominance Space Black, úhel 105° a chobotnice hanby.
5. **Hypergamy Tier List Matrix:**
   - Tabulkové srovnání od Tier S po Tier F.
6. **Recenze z kaváren & Live Toast Ticker:**
   - Autentické svědectví z Karlína, Letné a Starbucks.
   - Živé simulované notifikace o nákupech a swapování v reálném čase.
7. **Apple-Grade design & Web Audio FX:**
   - Dark mode (Space Black) a Light mode (Silver).
   - Zvukové efekty generované přímo přes Web Audio API bez externích knihoven.

## 🚀 Lokální spuštění
Pro zobrazení webu stačí spustit jakýkoliv lokální HTTP server:
```bash
python3 -m http.server 8080
```
A otevřít v prohlížeči `http://localhost:8080`.
